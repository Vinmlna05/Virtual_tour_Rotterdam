1. Download file `.glb` dari link diatas, lalu masukkan ke folder project.
2. Daftarkan nama file pada `MODEL_FILES` di HTML.
3. Ubah `SHOW_3D_MODELS = true`.
4. Jalankan melalui server lokal, jika ingin ubah posisi tambahkan `?edit=1` pada URL.
5. Atur posisi, skala, dan rotasi melalui **Object 3D Editor**.
6. Copy koordinat hasil pengaturan dan masukkan ke file HTML.
